# SAP — Sistema de Apoyo Psicopedagógico

Repositorio público de descargas y materiales de **SAP — Sistema de Apoyo Psicopedagógico**.

SAP es una aplicación de escritorio para organizar el acompañamiento y seguimiento escolar, integrando en un mismo circuito:

- estudiantes y evaluaciones;
- observaciones cualitativas;
- planes de apoyo;
- seguimiento de avances;
- informes individuales;
- estadísticas institucionales.

Los datos pedagógicos se almacenan localmente en la computadora de la institución.

## Versión

Versión piloto conocida: **67.8-piloto**.

Los instaladores, manuales y actualizaciones públicas se publicarán en este repositorio cuando estén disponibles.
